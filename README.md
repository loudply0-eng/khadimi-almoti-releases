# خادمي المطيع — الإصدارات والتحديثات

هذا المستودع العام مخصص لنشر **الإصدارات الرسمية وملفات التحديث** لتطبيق خادمي المطيع.

## الغرض من المستودع
- توفير روابط الإصدارات الرسمية وسجل التغييرات.
- نشر ملفات التحديث وبيانات الإصدار اللازمة لآلية التحديث داخل التطبيق.
- نشر قيم التحقق مثل SHA-256 والتوقيعات الرقمية عندما تصبح آلية التوقيع جاهزة.

## تنبيه أمني مهم
- لا ترفع الشيفرة المصدرية الخاصة إلى هذا المستودع.
- لا ترفع مفاتيح التوقيع أو كلمات المرور أو رموز الوصول أو ملفات الإعداد السرية.
- لا ترفع محادثات المستخدمين أو قواعد بياناتهم أو ملفاتهم أو نماذج الذكاء الاصطناعي الخاصة بهم.
- لا تعتبر أي ملف إصدار موثوقاً لمجرد وجوده هنا؛ يجب أن يتحقق التطبيق من سلامة الملف وتوقيعه قبل تثبيته.

## المستودع الخاص
الشيفرة المصدرية والتطوير محفوظان في مستودع خاص منفصل. هذا المستودع مخصص للتوزيع العام فقط.
